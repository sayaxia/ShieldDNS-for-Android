# ShieldDNS 内置规则
# 语法与自定义规则一致：||域名^ 拦截该域及其子域，@@||域名^ 例外放行（优先于拦截），* 通配
# 分段标记：# == [dns] == 同时作用于 DNS 层和 SNI 层；# == [sni] == 只作用于 SNI 增强拦截
# 不需要某条时，在「过滤订阅」里把这条内置策略整条关掉即可，或把需要的例外写进自定义规则

# == [dns] ==

||*-reading-ad.*^
||*-ad-sign*^
||*-mgsdk-sign*^

# 埋点/日志（misc-hl、applog-hl）照旧被外部订阅拦掉，正片靠不命中拦截规则自然放行。
