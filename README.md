# ShieldDNS for Android

桌面版 [ShieldDNS](https://github.com/sayaxia/ShieldDNS) 的安卓版本：本地 DNS 过滤，不需要 root，不接管除 DNS 以外的任何流量。

## 系统要求

- Android 8.0（API 26）及以上
- 安装包为 `arm64` / `x86_64` 通用，纯 Kotlin，无 native 库

## 它做什么

安卓不允许普通应用监听 53 端口，所以这里用 `VpnService` 建一个**只有 DNS 走它**的本地 VPN：

- 虚拟接口地址 `10.111.0.2/32`，把 `10.111.0.1` 注册成系统 DNS，只给这个地址加一条 `/32` 路由；
- 应用发出的 DNS 查询（UDP:53 与 TCP:53）进来后解析 QNAME，命中规则就**本地造应答**（NXDOMAIN，或 `0.0.0.0` 的一条 A 记录），不命中就经受 `protect()` 保护的 socket 转发给上游，再把应答写回 tun；TCP 查询由内置的最小 TCP 栈封装回客户端；
- 其余所有流量（网页、视频、下载）**完全不经过 VPN**，不额外绕一层，也不影响网速。

另有一个可选的 **SNI 增强拦截**（默认关闭）：只把白名单里的那一个应用拉进 VPN，接管它的 TCP:443，在 TLS 握手时读出明文域名。用于应用走 HTTPDNS 拿 IP 直连、DNS 层根本看不见的场景；命中广告域名时可以直接断开该连接。不接管 UDP，不做中间人解密。

启动即「待命」：不自动接管，需要你在概览页打开开关并授权一次 VPN。
内置了一份针对字节系短剧广告的规则，在「过滤订阅」里置顶显示，可整条关掉，也可点「更新」从仓库的
`rules/default-rules.txt` 拉最新版；拉不到时用随包副本，离线照样拦。也可以自己加订阅或自己写规则。
规则按来源分层：自定义规则优先于订阅，订阅按列表顺序从上到下，内置策略垫底。

## 页面

| 页面 | 内容 |
| --- | --- |
| 概览 | 状态与开关、监听地址、生效规则数、订阅更新时间、更新全部订阅；查询总数 / 已拦截 / 拦截率 / 缓存命中 / 生效规则 / 运行时长；最近 8 条查询 |
| 过滤订阅 | 置顶一条内置策略，其余是订阅；每条一个开关决定是否参与拦截；长按进入多选可批量删除；按住右侧手柄拖动调整优先级 |
| 自定义规则 | 一个编辑框，保存并应用 / 清空；标题右侧「?」查看完整写法 |
| 查询日志 | 内存保留最近 2000 条，按 200 条一页往上加载；可按「全部 / 拦截 / 放行」筛选；点任一条看完整域名并一键复制域名 |
| 设置 | 上游 DNS（跟随系统 / 自定义）、拦截响应（NXDOMAIN / 0.0.0.0）、缓存与自动更新、SNI 增强拦截、关于 |

## 规则语法

复刻桌面版支持的 AdGuard 子集：

```
||ads.example.com^        阻断该域名及所有子域
@@||ok.example.com^       例外（优先于阻断）
example.com               裸域名，同样覆盖子域
0.0.0.0 tracker.example   hosts 写法
127.0.0.1 beacon.example  hosts 写法
```

`!` / `#` 开头的注释、`##` 外观规则、`$options`、正则、`*` 这类不支持的行会被跳过。
匹配方式是「按标签逐级截断查哈希表」，几万条规则也是常数级。

## 使用

1. 安装 APK。
2. 打开应用 → 概览页打开开关 → 系统弹出 VPN 授权 → 允许。
3. 到「过滤订阅」加一条规则源（例如 AdGuard DNS filter 的 `https://…/adguard.txt`），点更新。
4. 想要开机后一直生效，可在系统设置里把 ShieldDNS 设为「始终开启的 VPN」。

## 已知限制

- 处理 **UDP:53 与 TCP:53**；只有发往本地 DNS 地址 `10.111.0.1` 的 DNS 流量会进 VPN，不止「命中的查询」——未命中的也要过一遍规则判断，再由受保护的上游 socket 转发。其它流量不进 VPN。
- 不处理 DoT(853) / DoH。开了系统的「私人 DNS」时查询不走这里，等于绕过本应用；要用本应用请先关掉私人 DNS。
- 拦截靠伪造应答（NXDOMAIN 或 0.0.0.0），不修改系统 DNS 设置，卸载/关闭开关即刻恢复。
- 上游默认跟随系统：只取底层网络（显式排除本应用自己的 VPN 网络，永远不会把 `10.111.0.1` 当上游），按「有线 > WLAN > 蜂窝」排序取系统下发的 IPv4 DNS；切网、开关 WLAN/蜂窝都会自动刷新（网络回调 + 每 5 秒兜底重算），拿不到时回退 `223.5.5.5` / `8.8.8.8`。

## 隐私

- 查询日志只存在本机内存里，最多 2000 条，关掉开关或退出应用就没了，不会上传。
- 订阅规则、配置存在应用私有目录（SharedPreferences）。
- VPN 只把 DNS 收进本地接口，其它流量不经过本应用，也不做任何转发记录。

## 版本记录

`0.2.1` — 正式版。在 DNS 拦截之上新增 SNI 增强拦截（只挂指定应用、读 TLS 明文域名、命中广告域名直接断开），自定义规则支持 `*` 通配，广告规则同时下沉到 DNS 层避免重连风暴，诊断包扩充 SNI/TCP 统计；界面去掉解释性长文案，设置页收进一屏。

`0.2.0v5` — 新增 SNI 增强拦截：对指定应用接管 TCP 流量、在 TLS 握手取明文域名，补上 HTTPDNS 直连的盲区；命中广告域名直接阻断，正片域名优先放行。

`0.1.5` — 新增诊断导出：设置页可把最近 2 分钟 / 10 分钟 / 全部的查询日志导成 CSV 并直接分享；日志条目补充 UDP/TCP 协议与缓存命中标记。

`0.1.4` — 与 0.1.3 功能相同，仅递增版本号，用于验证应用内自升级链路。

`0.3.0` — 订阅体系重构：内置策略变成可更新的置顶订阅、每条订阅带开关、长按多选批量删除、拖动调优先级；规则引擎改为分层（自定义 > 订阅顺序 > 内置）；自定义规则加语法体检。

`0.2.1` — SNI 增强拦截（DNS + SNI 双层），规则支持 `*` 通配。

`0.1.3` — 新增检查更新与自升级：读 GitHub Release 最新版本，有新版可一键下载（带 sha256 校验）并唤起系统安装器。

`0.1.2` — 支持 TCP:53；关掉开关后 VPN 与通知即时撤销；上游只取底层网络并跟随切网刷新；查询日志上限 2000 条并支持拦截/放行筛选与详情复制；订阅更新只有内容真变化才提示。

`0.1.1` — 修掉「未开启时概览页只剩开关」「关闭开关又自己弹回」「自动更新要等更新过一次才生效」三个问题；概览页不再显示上游 DNS。

`0.1.0` — 首个可安装版本：VPN 形式的 DNS 过滤、订阅、自定义规则、日志、设置、缓存、通知栏常驻与「暂停防护」。
